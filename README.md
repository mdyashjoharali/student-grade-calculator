# Student Grade Calculator

## Description
This project calculates student grades based on their marks using Python conditional statements.

## Internship Information
This project was completed as part of the Internship Program at Veda Technology.

## Features
- Grade calculation using Python
- Conditional statements (if, elif, else)
- Student marks analysis

## Grade Criteria
90-100 = A+
80-89 = A
70-79 = B
60-69 = C
50-59 = D
Below 50 = F
